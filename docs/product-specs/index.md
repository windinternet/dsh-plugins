# 产品规格索引

每个插件都必须有一份产品规格。规格回答"这个插件要做什么、怎么算做完了"，
而不回答"怎么实现"（那是代码与设计文档的事）。

| 插件     | 规格                         | 状态   |
| -------- | ---------------------------- | ------ |
| dockyard | [`dockyard.md`](dockyard.md) | 实验性 |

规格与 [`../../plugins.json`](../../plugins.json) 的 `specs` 字段双向绑定：
登记了规格就必须存在，存在规格就必须被登记。
