# 技术债追踪

技术债像高息贷款：持续小额偿还好于累积后痛苦地一次解决。本文件记录**明确延后**的问题，
而不是默默忽略的问题。每一条都要有：现象、影响、当前绕过方式、触发条件。

不在本文件里的问题，等于没人知道。发现债务时先在这里写一行，再继续手头的事。
